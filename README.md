# MOTAKAMEL Agency — موقع ثابت (من غير سيرفر)

موقع عربي/English + صفحة `/team` + لوحة أدمن `/admin`. كله ملفات ثابتة — ينفع على Vercel أو أي استضافة (Netlify, GitHub Pages, cPanel).

## إزاي أعدّل المحتوى
1. افتح `https://موقعك/admin` (أو `/admin` على جهازك).
2. عدّل أي حاجة (نصوص، صور، موظفين، أعمال). بتتحفظ أوتوماتيك **على متصفحك**.
3. اضغط **⬇ تصدير للنشر** → هينزل ملف ZIP فيه `content.json` وفولدر `uploads/`.
4. فك الـ ZIP وحط `content.json` و`uploads/` جوه فولدر `public/` (استبدل الموجود) وارفع/اعمل Deploy.

> الأدمن شغال في متصفحك بس، فأي حد يفتحه مش هيقدر يغيّر حاجة في الموقع الحقيقي. التغيير بيظهر للزوار بس لما ترفع الـ ZIP.
> الفيديوهات الكبيرة: استخدم روابط YouTube / Drive / Vimeo أو حط الملف في `uploads/` وسجّل مساره.

## تجربة على جهازك
`node serve.js` ثم افتح http://localhost:3000
